# Data card: fictional policy evidence

## Source and rights

This dataset was authored specifically for the Evidence Gate portfolio reference implementation. Northstar and Harbor are fictional tenants. The corpus contains no employer documents, customer contracts, personal data, secrets or scraped material. The original fictional dataset is distributed under the project's MIT license.

The data is generated by `evidence_gate/fixture.py`. The generator is the source of truth for the JSONL and JSON files; fixed expected answers are authored from the documented policy facts, never inferred from the system output.

## Grain and contents

One corpus row represents one version of one managed policy claim for a tenant and region. There are 58 rows: eight topics times two regions times three versions (48); eight Harbor records; and two conflicting global export records. The three versions are current approved, expired approved, and current unapproved draft.

One evaluation row represents one query with a trusted tenant/role context, an optional region, an as-of date, and an expected contract outcome. There are eight development and 24 preassigned holdout cases. The holdout contains 17 answerable cases and seven cases requiring clarification or abstention.

| Field | Meaning |
|---|---|
| `id` | Unique document/version identifier |
| `tenant` | Tenant identifier used before scoring |
| `title`, `content` | Original searchable English text |
| `claim_key` | Managed fact identity linking versions and regional scopes |
| `claim` | Verbatim supported answer span in `content` |
| `region` | `us`, `eu`, or `global` |
| `valid_from`, `valid_to` | ISO dates; interval is `[valid_from, valid_to)`; null end means no stated end |
| `approved` | Authoritative approval flag |
| `roles` | Any listed role may retrieve the record within its tenant |
| `source` | `fixture://` record locator, not an external URL |

## Construction choices and limitations

Distractors deliberately repeat matching terms so that relevance can be separated from authority. This creates an adversarial regression fixture, not representative retrieval traffic. Correctness expectations are narrow, exact fact spans rather than free-form judgments.

The corpus author also wrote the evaluation cases. The development/holdout division prevents reporting development cases as holdout evidence, but does not create an independently authored benchmark. No hyperparameter search is run. These data establish behavior on the stated scenarios; they cannot establish production accuracy, business savings or model generalization.

Approved metadata, claim keys and curated fact spans are assumed correct inputs. A deployed system would need governance and validation for those fields. This implementation does not infer factual authority from document wording and does not solve semantic contradiction detection in arbitrary prose.

## Reproducibility

`python -m evidence_gate fixture` recreates both files. `python -m evidence_gate benchmark` records their SHA-256 hashes and the canonical corpus version in `results/metrics.json`. The date used by the recorded experiment is fixed at 2026-11-04, rather than changing with the computer clock.
