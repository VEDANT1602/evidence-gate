# Source and measurement provenance

This repository is the standalone form of Vedant Thaker's `projects/evidence-gate` project in the [Applied AI and Decision Systems portfolio](https://github.com/VEDANT1602/DataScienceProject). The original portfolio records AI implementation assistance in its [provenance statement](https://github.com/VEDANT1602/DataScienceProject/blob/ef9c14c01163ad3eadb3eaa673c0073b14478184/docs/provenance.md).

The source snapshot is commit [`ef9c14c01163ad3eadb3eaa673c0073b14478184`](https://github.com/VEDANT1602/DataScienceProject/tree/ef9c14c01163ad3eadb3eaa673c0073b14478184/projects/evidence-gate). The project history was extracted with `git subtree split` in an isolated local clone. Filtered commits retain their original author, timestamp and message; their commit IDs change because the parent history and tree paths change. The extraction does not change the source portfolio or its history.

The extracted tree was verified as `817f5b15b84b0ac93db0e4f2fcccb8620749d954`, identical to the project's tree at the source commit before packaging. [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json) records the original file blobs, filtered head and source tree. Packaging adds this statement, standalone CI and a link from the README, while retaining existing project ignores. Runtime code, fixtures, data contracts and recorded experimental outputs remain unchanged.

The numerical results retain their original dates, datasets, environment and limits. Unit tests validate the standalone checkout; extraction is not a new benchmark or a new employer deployment. Employer and customer code/data are not included. Dataset and conceptual-reference terms remain those documented in the original project.
